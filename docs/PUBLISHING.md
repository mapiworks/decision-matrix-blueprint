# Publication checklist

This repository is prepared as a useful public reference project, but it is intentionally private/local until its owner approves publication.

Before making it public:

1. Confirm the repository owner and final name.
2. Review every commit and tracked file for secrets, private data, and accidental internal URLs.
3. Run `./scripts/secret-scan.sh` and validate both examples against the JSON Schema.
4. Check that external links are contextual and useful, not a link-only promotion.
5. Confirm that the MIT license and attribution are appropriate.
6. Publish only after explicit owner approval, then verify the public README and example URLs.

The project should remain valuable if the Octo Thinks links are removed. Those links are references to a related live tool, not a substitute for documentation or functionality.
