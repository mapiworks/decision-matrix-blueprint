# Contributing

Contributions should make the format clearer, safer, or easier to reuse.

Please:

1. Keep examples generic and free of personal data.
2. Explain assumptions in `notes` or score `reasoning`.
3. Prefer stable, public sources and include `https://` URLs.
4. Run `./scripts/secret-scan.sh` before opening a pull request.
5. Do not add credentials, private datasets, scraped personal information, or claims of professional advice.
